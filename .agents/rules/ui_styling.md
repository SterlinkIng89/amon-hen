# UI Styling Rules

- **No Glows**: Do NOT use any glow effects or drop-shadows (e.g., `drop-shadow-*`, `shadow-[0_0_*]`) in the UI components. Stick to clean, flat designs or standard subtle shadows if absolutely necessary.
- **No All-Caps Text**: Do NOT use fully uppercase text (e.g., `ASDASDA`). Text should be displayed with normal sentence casing or title casing (e.g., `Aasdasda`). Do not use Tailwind's `uppercase` class unless specifically requested for a tiny badge or label, but generally avoid it.
